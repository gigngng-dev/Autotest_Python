ДЕФЕКТ #1
Заголовок:    capitalize() делает строчными ВСЕ буквы, кроме первой
Компонент:    StringUtils.capitalize()
Серьёзность:  Minor
Приоритет:    Low

Описание:
  В коде сказано: "делает первую букву заглавной и возвращает
  этот же текст". Пользователь ожидает, что изменится только первая
  буква, а остальной текст останется без изменений.

  Однако внутри метода вызывается str.capitalize(), который в Python
  делает первую букву заглавной, а ВСЕ ОСТАЛЬНЫЕ — строчными.

Шаги воспроизведения:
  1. Создать экземпляр StringUtils()
  2. Вызвать utils.capitalize("hello WORLD")

Ожидаемый результат:
  "Hello WORLD"  (только первая буква стала заглавной)

Фактический результат:
  "Hello world"  (буква W тоже стала строчной)

Комментарий для разработчика:
  Если требуется именно такое поведение — документацию нужно исправить.
  Если требуется поведение из документации — заменить string.capitalize()
  на string[0].upper() + string[1:] (с обработкой пустой строки).


ДЕФЕКТ #2
Заголовок:    contains() возвращает True при поиске пустой строки
Компонент:    StringUtils.contains()
Серьёзность:  Minor
Приоритет:    Medium

Описание:
  Метод contains(string, symbol) логически должен проверять наличие
  конкретного символа или подстроки. Пустая строка "" не является
  символом и не может "содержаться" в другой строке.

  Однако при передаче пустой строки в параметр symbol метод
  возвращает True для ЛЮБОЙ строки, включая пустую.

Шаги воспроизведения:
  1. Создать экземпляр StringUtils()
  2. Вызвать utils.contains("abc", "")
  3. Вызвать utils.contains("", "")

Ожидаемый результат:
  False  (пустой символ не содержится в строке)

Фактический результат:
  True

Комментарий для разработчика:
  Причина: string.index("") всегда возвращает 0, поэтому
  условие "index > -1" даёт True.
  Исправление: добавить явную проверку if not symbol: return False
  в начало метода.

ДЕФЕКТ #3
Заголовок:    Все методы класса падают с необработанным исключением при передаче None
Компонент:    StringUtils (все методы)
Серьёзность:  Major
Приоритет:    High

Описание:
  Ни один метод класса StringUtils не проверяет входные параметры
  на None. При передаче None выбрасываются низкоуровневые исключения
  (AttributeError, TypeError), которые неинформативны для
  пользователя библиотеки.

  Это нарушает принцип fail-fast и делает отладку сложной.

Шаги воспроизведения:
  1. Создать экземпляр StringUtils()
  2. Вызвать любой из методов с аргументом None:
     • utils.capitalize(None)      → AttributeError
     • utils.trim(None)            → AttributeError
     • utils.contains(None, "a")   → AttributeError
     • utils.contains("abc", None) → TypeError
     • utils.delete_symbol(None, "a")   → AttributeError
     • utils.delete_symbol("abc", None) → TypeError

Ожидаемый результат:
  Метод либо:
    а) возвращает осмысленное значение (например, пустую строку
       или False), либо
    б) выбрасывает понятное исключение (например, ValueError
       с текстом "Input string cannot be None").

Фактический результат:
  AttributeError: 'NoneType' object has no attribute 'capitalize'
  (или аналогичное необработанное исключение из внутренней
   реализации Python).

Комментарий для разработчика:
  Рекомендуется добавить валидацию входных параметров в начало
  каждого метода. Например:
    if string is None:
        raise ValueError("Input string cannot be None")
  Это сделает API предсказуемым и безопасным.
